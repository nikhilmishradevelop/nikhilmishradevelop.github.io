# ZS Patient Drug-Switch Prediction (MachineHack, 2020) — 1st on the leaderboard

Identify patients likely to switch treatment in the rheumatoid-arthritis market, from event-level patient histories. Judged on AUC, then on time and memory cost, with finalists presenting at MLDS 2020.

- Rank: 1st on the final leaderboard (66 active participants). See [leaderboard snapshot](../../assets/leaderboards/machinehack-zs-patient-drug-switch.jpg).
- Approach: deep per-patient aggregations plus "recency" features (first/last time each event happened), LightGBM and XGBoost models, blended. Run order is in [SOLUTION_NOTES.md](SOLUTION_NOTES.md).
- Write-up: [Analytics India Magazine](https://analyticsindiamag.com/deep-tech/patient-drug-switch-prediction-winners/)
- Original copy: [MachineHack solutions repo](https://github.com/analyticsindiamagazine/MachineHack/tree/master/Hackathon_Solutions/ZS-Patient%20Drug-Switch%20Prediction/Nikhil%20Kumar%20Mishra)

Data is not included (competition rules).

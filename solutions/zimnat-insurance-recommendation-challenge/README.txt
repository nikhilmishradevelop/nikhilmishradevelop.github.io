--------------------------------

Competition files are already placed in the "holar\Data" folder for this, don't move the files from there.



Note: For all the below notebooks use python and Jupyter notebook.
All the competition files are already in the same directory as the notebooks for the below notebooks. Don't move any of the files out from there.


2. Run the notebook "enc_all_lgb_v1.ipynb" to get output "enc_all_lgb_v1.csv".
3. Run the notebook "zimnat-m10-v2.ipynb" to get output "zimnat-m10-v2.csv".

8. Run the notebook "zimnat-m14-v4.ipynb" to get output "zimnat-m14-v4.csv". (requires GPU)

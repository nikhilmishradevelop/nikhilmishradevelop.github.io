## Repository layout

- `index.html`: the portfolio page, with all results data inline
- `assets/leaderboards/`: saved snapshots of each final leaderboard
- `solutions/<competition>/`: solution code submitted to the hosts, one folder per competition (MachineHack ones are copies from MachineHack's public solutions repo)

Competition datasets are not included, because the platforms' rules don't allow redistributing them. Each solution folder explains where to get the data.
